◆ AndThenAll()

template<class Fn, class... Ts, class... Es>
requires (sizeof...(Ts) > 0) && std::invocable<Fn, Ts...>
auto Thoth::Utils::AndThenAll ( Fn && fn,
std::expected< Ts, Es >... args )
constexpr

Check args (with first fail) and if it doesn't fail it will call fn with them.

fn must return an std::expected, and only runs when every argument holds a value. But even with that arguments are evaluated outside the function so this reports the first error but doesn't skip the work the others. The error types are merged with std::common_type. expected<void, E> is safe here.

AndThenAll(MakeUser, ParseName(json), ParseAge(json)); // expected<User, E>

Bridge between "a type" and "a value": ToValue<V>() gives back the non-type argument V, while ToValue<T>() gives T{}.

It lets an API accept the same callable either as a template type (a stateless functor) or as a non-type argument (a function pointer, a captureless lambda stored in a constexpr variable), so Fn<isBig>(x) and Fn(isBig, x) end up on the same implementation.
