Detailed Description

template<Utils::Serializable T>
struct Thoth::Http::NHeaders::Weighted< T >

Associates a header value with an RFC 9110 §12.4.2 quality weight.

The q member is in the inclusive range 0.000 to 1.000 and defaults to 1.0 when the wire value does not contain a q parameter. This type is used for comma-separated preference headers such as Accept-Encoding and Accept-Language.

Weighted<T> stores the parsed value in value and the preference in q. It only extracts the ;q= segment.

Template Parameters
TSerializable value carried by the weighted header element.
Example
using Language = Weighted<std::string>;
Language preferred{ "pt-BR", 1.0 };
auto fallback{ preferred.WithWeight(0.8) };
