Detailed Description

Fixed-size sliding window that accumulates intermediate Recvs between parse steps (head lines, chunk frames, body slices).

The storage is a lazily allocated unique_ptr (nullptr until the first Recv), so exchanges that never read a byte pay nothing (which is also what makes it pool-friendly, a Server can hand the whole struct back to a connection pool instead of freeing it).

Note
Members are intentionally public, the Server trio and the connection pools poke at them directly.
