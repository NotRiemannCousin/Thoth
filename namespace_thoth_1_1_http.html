concept  ConnectionConcept
 Concept for any synchronous Hermes socket (Client or Server-side) over which Thoth's wire algorithms can operate. Hermes' ClientSocket and ServerSocket are already structurally identical on this transfer surface — this concept simply formalizes it on Thoth's side, so HTTP algorithms don't need to know whether they are talking to a client or server socket.
