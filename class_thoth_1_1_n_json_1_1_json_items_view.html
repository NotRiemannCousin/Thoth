Detailed Description

template<bool IsConst>
class Thoth::NJson::JsonItemsView< IsConst >

A std::ranges view yielding (KeyView, Json&) pairs over the children of a Json.

Pairs each child with its array index or object key. Scalars and null yield an empty view. It models std::ranges::view_interface. String keys are string_view objects tied to the parent's lifetime.

Note
This view holds a non-owning reference to its parent. The parent must outlive the view.
