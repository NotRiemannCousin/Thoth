Detailed Description

template<bool IsConst, Utils::Serializable ... Ts>
struct Thoth::Http::NHeaders::MultiValueProxy< IsConst, Ts >

Typed proxy for multiple header values.

A MultiValueProxy adapts one header field to a typed vector. The proxy itself is a short-lived accessor.

Note
Given that it can't be stored in any sense, it is intentionally not a std::ranges::range. Call Get() or GetAsOpt() to materialize the parsed std::vector.
Template Parameters
IsConstWhether the proxy can modify its Headers object.
TsSerializable value types accepted by the multi-value proxy.
