Detailed Description

A subset of URL as defined in RFC 3986.

Note
Url is an immutable record: once parsed via FromUrl, its components cannot be mutated in place.
Warning
Views returned by this class are only valid for the lifetime of this Url instance, and are invalidated by move (the moved-from Url no longer owns the buffer). Do not store an AuthorityView or any string_view obtained from this class past the lifetime of the Url, uses the Copy methods instead.

◆ Resolve()

std::expected< Url, ThothError > Thoth::Http::Url::Resolve ( std::string_view  reference) const

Resolves a URI reference against this URL as base, per RFC 3986 §5.2.2.

Supports absolute references (returned verbatim as a parsed Url), relative-path references ("../v2/users"), same-document references (""), and fragment-only references ("#section").

Parameters
referenceA URI reference. Does not need to be absolute.
Returns
The resolved absolute Url, or an ThothError if the resolved result fails parsing (e.g. produces an invalid scheme).
