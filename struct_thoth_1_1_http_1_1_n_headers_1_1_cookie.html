Detailed Description

A Set-Cookie response field value (RFC 6265 §§4.1, 4.2).

The first two fields form the required name=value pair. The remaining fields model common cookie attributes, an unset optional attribute is not emitted. Boolean attributes such as Secure and HttpOnly are emitted when their flags are true.

Example
Cookie session{
.name = "session",
.value = "abc",
.path = "/",
.sameSite = SameSiteEnum::Lax,
.secure = true,
.httpOnly = true
};
