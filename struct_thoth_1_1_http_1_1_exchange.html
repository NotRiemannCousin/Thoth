Detailed Description

template<CommonSocketConcept Socket>
struct Thoth::Http::Exchange< Socket >

One live request handed to the Router, the Server side of an exchange.

The head is already parsed (a broken head never reaches a Router, the Server answers those itself through Http1::WriteErrorResponse) and the ReadContext is borrowed from the connection, so a handler can still pull the body from the wire through ReadAs. The exchange never owns the socket, the connection does, which keeps keep-alive (and a future connection pool) entirely in the Server's hands.
