Detailed Description

Represents the request-specific HTTP header fields.

The typed accessors use concrete models such as Range, EntityTag, Te, FreeWeightedHeader and FreeParameterizedHeader.

Example
RequestHeaders headers;
headers.Host().Set("example.test");
headers.Range().Add(NHeaders::Range{
NHeaders::PrefixedRange{ 0u, 1023u } });
auto host{ headers.Host().Get() };
