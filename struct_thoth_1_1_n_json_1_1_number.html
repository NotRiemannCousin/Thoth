Detailed Description

JSON number type — holds int64_t, uint64_t, or double.

The active alternative is determined at parse time:

  • A literal with '.' or exponent (e / E) → double.
  • A literal with a leading '-' → int64_t.
  • Any other literal → uint64_t (preserves the full [0, 2⁶⁴) range).

Cross-alternative equality (int64_t{1} vs uint64_t{1} vs double{1.0}) is not performed — operator== reflects the variant's active alternative.
