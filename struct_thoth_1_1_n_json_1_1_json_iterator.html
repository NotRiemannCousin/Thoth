Detailed Description

template<bool IsConst, bool IsItems = true>
struct Thoth::NJson::JsonIterator< IsConst, IsItems >

Bidirectional iterator over the children of a Json. It is designed to work only with Object and Array.

It IsItems is true, it yields all (KeyView key, Json value) pairs, with KeyView being the array indices or object key strings. Otherwise, it yields only the Json values.

Note
Despites being useless, for API simplicity this type always works with (KeyView key, StateIter it) and select IsItems will only change dereferencialization.
See also
Json::Items.
