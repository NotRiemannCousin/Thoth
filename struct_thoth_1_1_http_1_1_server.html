Detailed Description

template<class Router = BasicRouter<Hermes::RawTcpAsyncServer>, Hermes::AsyncListenerSocketConcept Socket = Hermes::RawTcpAsyncListener>
struct Thoth::Http::Server< Router, Socket >

The server. Owns the routing, the listener configuration (imutable, keep it right from the start), and the accept loop definition.

Not copyable, not movable. Run() is const and returns a sender, but you shouldn't call it twice. Stop() is thread-safe and idempotent.

template<class Router = BasicRouter<Hermes::RawTcpAsyncServer>, Hermes::AsyncListenerSocketConcept Socket = Hermes::RawTcpAsyncListener>
auto Thoth::Http::Server< Router, Socket >::Run ( ) const -> stdexec::sender auto

Start the accept loop. Returns a sender that completes when the server stops, it doesn't block.

This sender doesn't produces a value, it just execute the server loop. Given that, the completition signatures are only error(ThothError) (listener failure) and stopped() (cancellation via Stop).

Returns
A sender with error(ThothError) and stopped() channels.
