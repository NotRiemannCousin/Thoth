Detailed Description

Per-exchange ceilings and deadlines shared by Client and Server, independent of the HTTP flavour (1.x today, 2/3 reuse the same struct).

Http1 itself consumes maxBodyBytes, maxRequestLineBytes and maxHeadBytes directly, the remaining fields (connection ceilings and the Milliseconds deadlines) are consumed by the Client/Server connection managers, which translate them into socket Send options and into ReadContext::deadline.
