   CFileBodyA file on disk as a body, symmetric. The outgoing side serves it: Size comes from the filesystem metadata (no byte is read) and Read hands out slices through an internal bounce buffer, so a multi-gigabyte upload never gets materialized. The incoming side downloads into it: Write appends whole windows to the file and FinishWrite flushes (the RAII close on destruction stays as the failure-path backstop, where flushing would be wrong anyway). The stream is always binary, bytes are bytes and no EOL magic is welcome on the wire
